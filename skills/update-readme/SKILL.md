# Update README Skill

任意のリポジトリで動く汎用スキル。「対象リポジトリの README とその変更差分」だけを入力に、
README への反映が必要な変更を検出して最小編集で更新する。特定のディレクトリ構成やプロジェクトを
前提にしない。

## 処理フロー

1. **変更の確認** — `git status` と `git diff`（必要に応じ `git diff --staged`）で変更内容を把握
2. **README の特定** — 対象 README を特定して読み込む
   - デフォルトはリポジトリルートの `README.md`
   - 複数ある / サブディレクトリ構成の場合は、変更箇所に対応する README を選ぶ
3. **影響判定** — 「README の記載事項に直結する公開面の変更か」を判定
   - 該当しなければ **「README 更新は不要です」と伝えて終了**（過剰更新しない）
4. **更新案の作成** — 該当箇所だけを最小編集する差分案を作る（既存の構成・文体を維持）
5. **ユーザーに確認** — 変更箇所のビフォー/アフターを提示し、承認を求める
6. **反映** — ユーザーが承認したら README を更新

## README 更新が必要な変更（公開面）

以下のような、README の記載事項に直結する変更が対象。例えば:

- 公開機能・コマンド・API・スキル等の追加 / 削除 / リネーム
- インストール / セットアップ手順、前提条件、依存関係の変更
- 使い方・設定方法・実行例の変更
- プロジェクト構成（ディレクトリ・主要ファイル）の変更
- 環境変数・設定項目の追加 / 変更

## README 更新が不要な変更（スキップ）

以下は更新対象としない。例えば:

- 内部実装のリファクタ・文言調整で、公開された振る舞い / 使い方が変わらないもの
- テスト・補助設定ファイル（`.gitignore` など）の微修正
- 既に README に正しく反映済みの内容

## 編集時の注意

- **全面再生成しない** — 手書きの説明・既存の文体・言語（日本語 / 英語）を壊さない
- 該当セクションだけをピンポイントで編集する
- 一覧表・リストなどは、既存行のフォーマットに合わせて行を追加 / 削除 / 修正する
- README が存在しない場合は「README がありません。新規作成しますか?」と確認する

## ユーザーへの確認フォーマット

```
以下のとおり README.md を更新します:

更新対象:
  - README.md

変更箇所:
  ## スキル一覧
  - Before: （該当行 or なし）
  + After:  （更新後の行）
```
